// PIPELINE

Every stage of recon, wired together

Each feature below runs as one stage in a single automated pipeline — from passive discovery to live takeover verification.

enum --passive

Passive enumeration

subfinder, assetfinder, and amass run in parallel to pull subdomains from public sources with no traffic to the target.

enum --active

Active bruteforce

shuffledns drives wordlist-based bruteforcing with auto-generated resolvers for deeper coverage on --active runs.

resolve

DNS resolution

dnsx resolves every discovered name to confirm which subdomains actually exist before they're probed further.

probe --http

HTTP probing

httpx captures status codes, page titles, detected tech stacks, and response times for every live host.

scan --takeover

Takeover detection

nuclei runs a strict double-verification pass so only subdomains vulnerable in both passes get reported.

--web

Live dashboard + CLI

Watch scans stream in real time over SSE in a terminal-styled Next.js dashboard, or run the whole pipeline headless via ./scanner.

// TAKEOVER DETECTION

Double-verified, not single-pass

Transient DNS conditions produce false takeover reports in most scanners. ReconX only reports a host when it's confirmed twice.

01

Pass 1 — broad scan

nuclei scans every live subdomain against takeover fingerprint templates and flags candidates.

02

Pass 2 — re-scan candidates

Only the hosts flagged in pass 1 get re-scanned, filtering out anything that was a one-off network blip.

03

Report intersection

A subdomain only lands in takeover.txt if it's still vulnerable in both passes.

✓ Result: zero false positives from transient network conditions.
